# 水利施组目录

只在当前草稿是水利工程技术标时使用本技能。不要套房建、市政目录。

1. 一级章只用招标书施工组织设计或技术评分表里的评审因素。编制说明不要单独成章；编制依据和工程概况放在施工方案章第一节。
2. 施工方案按工程量清单分项展开，节名带数量。每一分项写工艺流程、分步施工、质量控制要点。测量放线、降排水、季节性施工（含农忙、灌溉期）按范围单列。拦河筑坝必须有导流或围堰。
3. 重难点章先写工程特点与重难点识别，再按「数量＋问题」列 5～8 条。每条下面固定三节：重难点分析、重难点解决措施、保证措施汇总。不要用「难点是什么／为什么难／怎么办」。
4. 高标准农田、灌区还要写：施工期不得中断灌排、分段施工与临时导流、农忙保障、少占耕地、临时用地复垦。
5. 物资、机械、劳动力若评分表分列就分章。附表按招标原文放在附件下。

# 改水利施组正文

1. 先读工作区 `eng_facts.txt` 或 `water_facts.txt`（区段、构筑物座数、装机、工程等别、勘察资料、规范编号）。没有的项写「【待核实】」或「【待补】」。
2. 用 `read_chapter` 看要改的那一节。混凝土的强度、抗渗、抗冻成组写；智慧工地写数据来源、采集频次、预警阈值、触发动作、责任岗位。
3. 用完整 Markdown 调用 `replace_chapter`。被拒绝时按返回的拦截项改正文再提交，不要绕过这个工具。
4. 不要调用 `run_skill_script` 做校核，写回时后端已经校核。不要打开浏览器，不要手写 Word。
